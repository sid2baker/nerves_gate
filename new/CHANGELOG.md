# Changelog

## Unreleased

### Added

- Local development workspaces keep newly created apps on the same checkout's SDK instead of switching to a published dependency.
- Workspace `mix setup` downloads and SHA-256-verifies the pinned QEMU firmware when the default image is missing. Existing images and custom firmware paths are preserved; no GitHub CLI is required.

## 0.1.1 - 2026-10-21

### Fixed

- `mix setup` can fetch dependencies for additional apps after workspace tooling has been compiled.

## 0.1.0 - 2026-10-21

### Added

- Generate app-development workspaces with independent OTP applications, simulator configuration and short Mix commands for adding, testing, installing and packaging apps.

### Fixed

- Workspaces generated by an installed archive include their formatter configuration and Git ignore files.
