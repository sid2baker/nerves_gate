# Produce a reproducible research synthesis

Use this method when an understanding request needs several external sources, a
stated search boundary, or conclusions that combine evidence across sources.
The result is a `research-synthesis`, not authority to make the accountable
value decision that can follow it.

## Fix the search boundary

Before broad discovery, record the question, date, relevant source classes,
search services or collections, exact queries, time or language limits,
inclusion and exclusion rules, result caps, and the stopping condition. Pilot a
query against one known relevant source when practical. Translate a query for
each service instead of assuming that field syntax is portable.

Use primary and current sources for material facts when available. A search
result, title, excerpt, citation count, or machine summary is a discovery lead,
not proof of the source's full claim. Record access failures, truncated results,
ranking limits, paywalls, and unavailable full text.

For a bounded engineering survey, inspect enough complementary sources to
answer the question and state the coverage limit. Use the term `systematic
review` only when a fixed protocol, suitable databases, complete recorded
searches, screening decisions, exclusion reasons, reconciled counts, and the
required independent review process support that claim.

## Select and extract evidence

Deduplicate records without discarding distinct versions or reports. Link a
preprint, final publication, correction, protocol, or follow-up when they belong
to one work or study. Record which version supports each material claim.

For each included source, capture identity, publication or update date, source
type, relevant claim, direct supporting location, important method or context,
limitations, and conflicts of interest when material. Verify that the source
exists and that its content supports the cited claim; identifier registration
or URL access alone is not enough.

Keep observed source facts separate from calculations, interpretations, and
inferences. Apply the inclusion rules consistently to supporting and contrary
evidence. Do not use author reputation, venue, or citation count as a substitute
for relevance or evidence quality.

## Synthesize and report

Group the result by finding, theme, mechanism, or decision question. Compare
sources inside each group. Do not produce one disconnected summary per source
when the request needs synthesis.

For each conclusion, state the supporting sources, contrary evidence, evidence
quality, uncertainty, and scope. Mark a claim Unknown when direct support is
missing. Report the question, method, query and date log, coverage, included and
excluded source classes, findings, conflicts, gaps, and reproducibility limits.
Stop when more searching cannot change the next consumer's decision or when the
declared boundary is exhausted.
