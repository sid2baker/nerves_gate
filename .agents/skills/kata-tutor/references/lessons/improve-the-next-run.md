# Improve the next run

**Practice:** Change one part of the next assignment from observed results.

Concepts: [reflection](../concepts/reflection.md) and
[feedback](../concepts/feedback.md).

1. Compare the intended and actual result.
2. Select one behavior or assignment condition that caused useful or harmful
   effects.
3. Preserve what worked and change one high-value part of the next request.
4. State the evidence for the change and what signal will test it next time.

Complete when the learner writes one justified change for the next assignment.
Do not turn one result into a broad rule or mastery claim.
