# Bound the work

**Practice:** Choose what belongs in one assignment and what does not.

Concepts: [scope](../concepts/scope.md) and
[constraints](../concepts/constraints.md).

1. Start with the stated outcome and list only the work required for it.
2. Identify one nearby result that can cause boundary confusion.
3. State it as an exclusion or a separate decision.
4. Add only constraints that change an acceptable result.
5. Give feedback on one ambiguous boundary and invite a revision.

Complete when the learner states included work, an important exclusion, and
relevant limits clearly enough that the next worker does not need to guess.
