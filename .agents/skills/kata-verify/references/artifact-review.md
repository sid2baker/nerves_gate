# Verify an artifact

Use this method for documents, images, generated files, interface artifacts,
and other results whose content or rendering matters.

1. Identify the exact files and required audience or consumer.
2. Check required content, structure, data, links, and metadata.
3. Render or open the artifact with its normal consumer when practical.
4. Inspect clipping, overlap, unreadable text, broken navigation, incorrect
   state, missing assets, and misleading labels.
5. Check the relevant sizes, pages, states, or viewports named by the contract.
6. Confirm that generated output is reproducible when reproducibility is a
   requirement.

Text extraction or source inspection does not replace rendering when layout is
material. A screenshot does not replace interaction when behavior is material.
Report content and presentation results separately.
